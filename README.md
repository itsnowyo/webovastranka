# webovastranka 
Průvodce cestováním

1. Domů – úvodní stránka s hlavními informacemi
2. Destinace – přehled všech míst
3. Evropa – evropské destinace (např. Prague, Vienna)
4. Asie – asijské destinace
5. Amerika – americké destinace
6. Tipy na cestování – rady a doporučení
7. Ubytování – informace o typech ubytování
8. Galerie – fotografie z cest
9. O nás – informace o autorovi
10. Kontakt – kontaktní formulář
